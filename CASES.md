# Case catalog

One row per `case/<name>` branch. **change** is the branch's single commit (the cause), **expected in the report** summarizes what `expected/<name>/reports/` pins as a result (the effect — the byte-exact pin is the artifact, this column is its human reading), and **proves** is the intent. Reading the middle two columns side by side is the review that matters: an intent whose evidence does not appear in the report column is a hollow pin.

Each row also has an executable twin: `expected/<name>/checks.grep` states the same intent as `must:`/`must-not:` patterns that the pinned report has to satisfy, so a case that stops proving its point fails instead of quietly passing — plus an `expect:` line authorizing the summary block, so a report that grows an EXTRA application or resource fails too instead of being pinned. Keep the two in step. Cases are BRANCHES (one focused commit off master); the `apps/` directory holds the app sources they render, and the two are not one-to-one: many cases edit only the Application catalog (`charts/apps/values-apps.yaml`), several cases share one app source. Keep this file in sync when adding a case (see the argocdf repo's `e2e-add-case` skill).

Counts quoted below are the report's own summary block (`affected` / `changed` / `+added -removed ~modified`); the exit code is `meta.yaml`'s (0 = nothing changed, 2 = changes present). Unchanged resources never appear in any report format, so a resource named here is one the case makes differ.

## lint (only these cases run a linter; they pin the label semantics)

`--lint` is NOT a suite-wide default: a linter runs only for the cases that pin findings — the ones below, plus `kustomize-basic` and `kustomize-overrides`, which share an app source carrying a deliberate `:latest` violation — each naming its adapter in `CASE_ARGS` in the harness's `run.sh`. Linting every app of every case spawned a policy engine per app per side for the 35 cases with no finding to pin, and that contention is what made `--lint-timeout` fire. A new case that asserts on lint output has to bring its own `--lint`.
